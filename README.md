# あおば青果 FAX注文デモ（YouTube撮影用）

メールで届いたFAX注文書を人が確認して確定する流れを見せるための、架空データだけの画面です。このリポジトリはデモ専用で、Supabase にも本番データにも接続しません。

得意先名・品名・電話番号・FAX番号はすべて架空です。担当者は出てきません。

## 起動

Node.js 20以降で、リポジトリのルートから実行します。

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5175` を開きます。データはブラウザの `localStorage` にだけ保存されます。

## 撮影の流れ

1. サイドバーの「デモデータを初期化」で最初の状態に戻す
2. 受信箱の「新着FAXを受信」を押す（メール取込の代わり。数秒「処理中」のあと「確認待ち」になる）
3. 行を開く。左が原本PDF、右が読み取り結果。黄色の行は読み取りに自信がない行
4. 黄色の行を原本と見比べて直し、「確定」を押す
5. 受信箱で「確定済み」になる

撮り直すときは、もう一度「デモデータを初期化」を押します。

## PDFの作り直し

`pdf-src/*.html` を直したあとに実行します。Google Chrome が必要です。

```bash
npm run pdf
```

生成先は `public/pdfs/` です。
